# Publication scope

Only authored frontend code, aggregated evidence JSON, authored reports, configuration, lockfile and validation assets are candidates for upload. Excluded: datasets, per-record predictions, source research code/reports, experiment logs, original prompts, models/checkpoints, secrets and images with unclear rights. No external imagery is used.
